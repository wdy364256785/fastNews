# 金融热点站草案

本站聚焦 A 股、港股、美股与全球黄金。临时站名为「金融热点（草案）」，MCP 前缀为 `finhot`。这些是开发草案，不代表已正式上线。

## 已完成

- `site/site.ts`：站点名称、简介、主题目录、关于页、日报与接入文案。
- `industry/taxonomy.ts` 与 `topics.json`：四个市场、宏观政策、市场知识和市场解读；机构与上市公司主题、金融标签和身份词典。
- `industry/prompts/`：金融相关性预筛、五维评分、标题摘要、术语、事实抽取和归组。保留七类内容的权重结构，改为行情、金融产品、研究方法、研究报告、行业事件、观点和教程。区分交易日、报告期、合约、币种、单位及传闻/审批/生效/成交阶段。
- `RELEASE=null`：金融站不显示“新模型”计数；相关测试改为验证没有此计数。
- 新行情图标与金融日报、周报、月报报头；公开固定文件继续使用站点占位符。
- 示例校准资料改为虚构金融事件，仅用于格式说明。

## 信源白名单与试抓

金十数据、财联社、Investing.com、金投网已由运营者明确选入白名单；东方财富、香港电台、美联储、世界黄金协会保留为原草案。共 8 家来源、9 个采集入口（Investing.com 分股票与大宗商品两个 RSS）。白名单代表内容来源选择，不代表已打开自动采集或取得全文许可。

所有信源均为 `enabled=false`，站内全文和全文再分发均关闭。首次运行 `scripts/seed.ts` 导入；以后已有配置不会覆盖。

金十当前接入的是公开文章列表，不是实时快讯流；财联社当前接入公开首页深度资讯，不是电报接口。需要这些实时流时，先选定公开、稳定或正式授权的接入方式。

官方入口：[金十公开资讯](https://news.jin10.com/)、[财联社](https://www.cls.cn/)、[Investing.com RSS 目录](https://www.investing.com/webmaster-tools/rss)、[金投网黄金](https://gold.cngold.org/)。

这里没有实时行情服务或付费新闻接口；所有热点来自报道与机构公告。世界黄金协会仅采集公开可访问资料，不使用付费区内容。信源分类标签用于标记来源，单篇市场标签由结构化模型依据正文判断。

## 你还需要决定

1. 正式站名、Logo、运营者、联系方式、域名与源码仓库地址；MCP 前缀和分类/主题 URL 应在接入前定稿。
2. 确认原草案信源是否保留；金十、财联社、Investing.com、金投网的名单选择已完成。是否追加证监会、沪深北交易所、港交所、上市公司公告、财经媒体或付费渠道，以及抓取和展示授权。
3. 哪些消息值得精选、哪些只是噪声；当前优先政策、财报、重大交易、异常行情和黄金供需，压低广告与无依据预测。请确认分类、主题和覆盖边界。
4. 标注 100–200 条实际金融资料，再按 `docs/selection.md` 校准。现有 `T1=60/T1_5=65/T2=76`、写作下限 50 均保留，尚未在金融样本上校准；单元测试不能证明真实选稿质量。
5. 确认日报出刊时间；目前保持北京时间每天 08:00、每周一 10:00、每月 1 日 10:30。
6. 确认使用规则、隐私说明、内容使用范围、访问日志与反馈保存期限。`site/pages/` 仍明确是未生效草案，不能当正式条款。
7. 模型供应商、模型/推理额度、API 密钥、预算、服务器、备份、备案与上线安排。

## 启动与检查

使用 Node.js 24.11+ 和 PostgreSQL 16/17，按 `docs/deploy.md` 部署。开发时保持 `COLLECT_ENABLED=false`、`MODEL_CALLS_ENABLED=false`、全部飞书推送及 `INDEXNOW_SUBMIT_ENABLED=false`。本地预览无需启动 worker。

```sh
npm ci
DATABASE_URL=postgres://127.0.0.1:5432/finhot_preview node scripts/migrate.ts
DATABASE_URL=postgres://127.0.0.1:5432/finhot_preview node scripts/seed.ts
npm run build -w @aihot/web
# 按 docs/deploy.md 分别启动 API 与 web
npm run typecheck
DATABASE_URL=postgres://127.0.0.1:5432/finhot_test npm test
node --test --test-concurrency=1 apps/web/tests/*.test.ts
node scripts/smoke.ts --base http://localhost:3000
```

测试库名必须以 `_test` 或 `_ci` 结尾，账号需有建库权限。浏览器测试需要 `npx playwright install chromium webkit`。

## 已有部署切换

这是新站草案。没有迁移或删除历史数据。已有部署不能只替换 JSON：旧 AI 信源不会因从文件删除而自动消失，请在后台暂停；旧文章、分类、主题与历史报告不会自动重新标注。上线前决定是否使用新的数据库，或保留旧库并逐项处理，做好备份后再操作。
